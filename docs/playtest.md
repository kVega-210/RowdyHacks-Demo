# Playtest checklist (QA-01)

Before: server up, host screen on a TV, sound on, keys printed (`scripts/keys/gen.sh`) and on lanyards, cards
printed, 4+ humans, a timer, someone taking notes in the table below.

| Moment | Watch for | Notes |
|---|---|---|
| Rules explanation | Time it (target < 90s using `/content/print/how-to-play.html`) | |
| Join + key claim | Anyone stuck on camera permission or QR at 1m? | |
| First briefing | Do people find their secret target (hold 🎯)? | |
| Minigames | Which ones confuse, which ones get laughs? Any unwinnable at speed? | |
| STEAL | Do people actually reach for keys? Scan time? Disputes? | |
| FREEZE | Accidental violations? Did anyone cheat? | |
| Bank raid | Fun or noise? | |
| Between | Cards played? Votes understood? Sabotage picked? | |
| Escape | Did anyone miss it? Was it tense? | |
| End | Winner clear? Roast landed? | |
| Overall | Total game time, energy curve, "play again?" | |

After: copy every confusion into a bug list (QA-02), fix the top 5, then tune `/shared/balance.json` (QA-03).
